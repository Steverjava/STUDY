# Markdown 标题语法

# 一级标题：“#”
一级标题：“====”
=======

## 二级标题：“##”
二级标题：“----”
-------

### 三级标题：“###”

#### 四级标题：“####”

##### 五级标题：“#####”

###### 六级标题：“######”

# Markdown 段落语法
即在空白行进行文本书写。

# Markdown 换行语法
在一段文字后使用两个空格或更多，然后使用回车键."  "  
即可换行.

# Markdown 强调语法
**粗体**：“\*\*x\*\*”、“\_\_x\_\_”  
*斜体*：“\*x\*”、“\_x\_”  
***粗斜体***：“\*\*\*xx\*\*\*”、“\_\_\_xx\_\_\_”、“\*\_\_xx\_\_\*”……

# Markdown 引用块语法
> 使用“>”进行引用  
>
> 引用块可以包含空白行
>> 引用块可以嵌套

# Markdown 列表语法
### 有序列表：
即使用“1. 2. 3.……”进行列表，markdown会自动排序，但必须开头为“1.”  
例如：
1. x
2. x
1. x
5. x
### 无序列表：
即使用“-、*、+”进行列表  
例如：
- x
- x

列表可以进行嵌套列表与其他元素，但是必须有对应的缩进控制

# Markdown 代码语法
使用（**\`\`**）包裹代码，即可以实现；如果代码中包含反引号，则使用双反引号即可  
例如：“这是一篇`Markdowm`笔记”  
例如：“``这是一篇`Markdown`笔记``”   

可以使用缩进至少四个空格或一个制表符来使用代码块  
例如：  

    这是  
    一篇
    markdown
    笔记

# Markdown 链接语法
链接文本放在中括号内，链接地址放在后面的括号中，标题在链接后面用引号包裹  
例如：  
这是一个网址 [贾魔司](http://steverjava.top "贾魔司")

也可以直接将URL或Email地址变成可点击的链接  
例如：  
<http://Steverjava.top>、<Steverjava@outlook.com>

链接可以被格式化，如强调，斜体等。  
并且也把链接表示为代码  
例如：  
本文档使用 **[MIT](https://mit-license.org/)** 许可证  
本文主要来源于我学习 *[Markdown](https://markdown.com.cn/basic-syntax/index.html)* 教程所做的笔记  
其他学习笔记可以在其他分支看到，如[`Python`](https://www.python.org/)

和其他的标记类语言相同，markdown也允许将链接进行分段。  
例如：  
[贾魔司][1]

[1]: <Steverjava.top> (贾魔司)

# Markdown 图片语法
添加图片使用 **"!"** 关键字，在 **"[]"** 中添加代替文本，在 **"()"** 中写图片链接，与链接语法一样可以在链接后加标题文本  
例如：  
![一张图片](/Material/sugar-00.png "糖？")  

也可以对图片添加链接，将上述内容用 **"[]"** 包裹，再在其后用 **"()"** 包裹链接即可  
例如：  
[![一张图片](/Material/贾魔司.png "emmm？")]("https://mp.weixin.qq.com/s/VwZ6T8t8_IgDa9NocF3Zqw")

# Markdowm 转义字符语法
也就是把一些在markdown里面有作用的字符 **"\、`、*、_、{}、[]、()、#、+、-、.、!、|"** 表示出来  
例如：  
这是反斜杠\\，这是井号\#。

# Markdowm 内嵌 HTML 标签
在行内不受限制  
例如：  
This **world** is blod. This <em>world</em> is italic.

区块标签需要在前后加空行与markdown部分分开，并且部分标签的开始与结尾不能用空白或Tab进行缩进。  
同时需要注意的是Markdown语法无法在HTML区块内使用。
