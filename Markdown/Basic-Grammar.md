# Markdown 标题语法

# 一级标题：“#”
一级标题：“====”
=======

## 二级标题：“##”
二级标题：“----”
-------

### 三级标题：“###”

#### 四级标题：“####”

##### 五级标题：“#####”

###### 六级标题：“######”

# Markdown 段落语法
即在空白行进行文本书写。

# Markdown 换行语法
在一段文字后使用两个空格或更多，然后使用回车键."  "  
即可换行.

# Markdown 强调语法
**粗体**：“** xx **”、“__ xx __”  
*斜体*：“* x *”、“_ x _”  
***粗斜体***：“\*\*\*xx \*\*\*”、“\_\_\_ xx \_\_\_”、“\*\_\_ xx \_\_\*”……

# Markdown 引用块语法
> 使用“>”进行引用  
>
> 引用块可以包含空白行
>> 引用块可以嵌套

# Markdown 列表语法
### 有序列表：
即使用“1. 2. 3.……”进行列表，markdown会自动排序，但必须开头为“1.”  
例如：
1. x
2. x
1. x
5. x
### 无序列表：
即使用“-、*、+”进行列表  
例如：
- x
- x

列表可以进行嵌套列表与其他元素，但是必须有对应的缩进控制

# Markdown 代码语法
使用（**\`\`**）包裹代码，即可以实现；如果代码中包含反引号，则使用双反引号即可  
例如：“这是一篇`Markdowm`笔记”  

例如：“``这是一篇`Markdown`笔记``”   

可以使用缩进至少四个空格或一个制表符来使用代码块  
例如：  

    这是  
    一篇
    markdown
    笔记

# Markdown 链接语法
链接文本放在中括号内，链接地址放在后面的括号中，标题在链接后面用引号包裹  
例如：  
这是一个网址 [贾魔司](http://steverjava.top "贾魔司")
