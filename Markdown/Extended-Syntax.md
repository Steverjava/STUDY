# Markdown 表格
添加表格，需要使用连续三个或者更多个 **(---)** 创建标题，然后用 **(|)** 分隔每列。  
例如：  
|Syntax|Description|
|---|---|
|Header|Title|
|Paragraph|Text|

关于对齐方式，使用 **":"**在 **"---"** 的左侧、右侧、两侧添加以来规定左对齐、右对齐、居中对齐。  
同时表格中的文字可以进行一些文本格式的设置。

# Markdown 围栏代码块
可以使用连续的三个 **"`"** 或者 **"~"** 在需要的代码前后包裹使其成为代码块，同时支持语法高亮，只需在反引号旁边加入一个指定语言即可。  
例如：  
```json
{
    "firstName": "John"
    "lastName": "Smith"
    "age": "25"
}
```

# Markdown 脚注
要添加脚注，需使用 **([\^1])** 标记，在方括号内插入标识符，标识符可以是数字或单词，但不能出现空格或制表符。在另一个中使用 **([\^1]: xxxx)** 就完成了脚注。同样后一个可以放在文章的结尾。  
例如：  
There are some balls.[^1]

[^1]: Just football.

# Markdown 标题编号
可以用以下手段进行标题编号与链接，适合在目录中转跳使用  
例如：  
### 标题 {#123}

[标题](#123)

# Markdown 定义列表
可以用以下手段实现定义列表，说明一个定义内容  
例如：  

一个定义
: 定义解释

# Markdown 删除线
在词前后用 **"~~"** 包裹即可  
例如：  
~~删除线~~

# Markdown 任务列表语法
任务列表是带有复选框的项目列表，可以用来表示代办任务是否完成，使用它仅需在正常无须列表的前提下加入 **" [ ]"** 即可，在其中加入 **"x"**  表示完成。  
例如：  
- [x] project 1
- [ ] project 2
- [ ] project 3
